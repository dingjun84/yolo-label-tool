# YOLO 标注工具 (YOLOTxtMaker)

一个功能完整的YOLO数据集标注工具，提供直观的GUI界面用于创建和编辑YOLO格式的标注文件。


注意：标注文件写在「保存路径」里。第一次使用（或上次选的目录已经不存在）时，必须先点 **设置保存路径**，才能打开图片或文件夹。选过之后会记住，下次启动自动填上，目录还在就不用重选。
## 使用

### Windows
在 [Release 页面](https://github.com/evilmordy/yolo-label-tool/releases) 下载 `YOLOTxtMaker.exe`，运行它。
### Linux
在 Release 页面下载 `YOLOTxtMaker.AppImage`，赋予执行权限后运行：

```bash
chmod +x YOLOTxtMaker.AppImage
./YOLOTxtMaker.AppImage
```

### macOS
在 Release 页面下载 `YOLOTxtMaker-mac.zip`，解压后运行其中的 `YOLOTxtMaker.app`。

### 下载代码在本地运行
需要 PyQt5（见 `requirements.txt`）。Windows / Linux：

```bash
pip install -r requirements.txt
python main.py
```

**macOS** 用仓库里的 `init.sh` 建好 conda 环境：

```bash
source init.sh
python main.py
```

「窗口截图」在 macOS 上依赖 `pyobjc-framework-Quartz`（已按平台条件写进 `requirements.txt`），
首次使用还需在 系统设置 → 隐私与安全性 → 屏幕录制 里授权；Windows 侧走系统 API，无需额外依赖。

## 发布新版本

合并到 `main` 后，GitHub Actions 会自动把 patch 版本加一（例如 `v2.0.1` → `v2.0.2`），构建 Windows exe、Linux AppImage、macOS zip，并发布到 [Release 页面](https://github.com/evilmordy/yolo-label-tool/releases)。

也可以继续手动推送 `v*` tag，或在 Actions 里点 **Run workflow**，同样会出三平台安装包。



## 快捷键

在标注界面中可用（焦点在窗口内时生效）：

| 按键 | 说明 |
|------|------|
| **R** | 切换到**标准矩形（Rect）**模式；之后点击「新添」会创建轴对齐矩形框 |
| **O** | 切换到 **OBB（旋转矩形）**模式；之后点击「新添」会创建带旋转控制点的框 |
| **P** | 切换到 **多边形（Seg）**模式；之后点击「新添」进入逐点绘制 |
| **Enter** | 绘制多边形时闭合当前多边形（至少 3 个顶点） |
| **Esc** | 绘制多边形时取消当前绘制 |
| **Ctrl+S** | 保存当前图片 YOLO txt |
| **Ctrl+Z** | 撤回上一步标注操作 |
| **A** | 新增标注（多边形绘制中不生效） |
| **Delete** | 删除当前选中标注；多边形绘制中则取消绘制 |
| **← / →** | 上一张 / 下一张图片（需先打开文件夹；单张图模式无效果） |
| **Backspace** | 多边形绘制中撤销上一个顶点 |
| **0~9** | 把选中框设为对应类别（0~9）；没有选中框时只切换「新建框的默认类别」 |
| **-** / **=** / **[** | 依次对应类别 10 / 11 / 12（`group_chat` / `contact_send_message` / `nav_groups_icon`） |
| **Ctrl+C** | 复制选中框到内存剪贴板 |
| **Ctrl+Shift+C** | 复制当前图片的全部框（可切到别的图片后粘贴，实现跨图继承） |
| **Ctrl+V** | 粘贴（整体偏移约 10px，并限制在图像范围内） |
| **Ctrl+D** | 进入/退出**盖框模式**；进入后左键单击即以点击点为中心复制一个同尺寸同类别框 |
| **Esc / 右键** | 盖框模式下退出 |

说明：R / O / P 只切换「当前新建框的类型」，不会改变已有标注；右侧单选按钮与上述快捷键一一对应。

默认快捷键可在菜单栏 **设置** 中自定义，并支持「恢复默认快捷键」。数字键与 Ctrl+C/V/D 等提效快捷键为固定绑定，不出现在设置面板里。

## 类别（classes.txt）

类别表在 [resources/classes.txt](resources/classes.txt)，**每行一个类别，行号（从 0 开始）就是写入 YOLO txt 的 class id**。以 `#` 开头的行和空行会被忽略。想增删类别直接改这个文件即可（标准矩形框在画布与右侧列表都显示英文类名）。

微信 / 企业微信界面截图默认的 13 类（与 yolo26 的 **c13** 严格对齐）：

| id | 英文类名 | 说明 |
|----|----------|------|
| 0 | self_avatar | 导航区当前登录账号头像 |
| 1 | nav_chat_icon | 导航栏「消息」图标 |
| 2 | nav_contacts_icon | 导航栏「通讯录」图标 |
| 3 | search_bar | 搜索框 |
| 4 | list_item | 列表中的一行：会话 / 联系人 / 搜索结果（由调用方按页面区分） |
| 5 | send_button | 发送按钮 |
| 6 | incoming_bubble | 接收的消息气泡 |
| 7 | outgoing_bubble | 发送的消息气泡 |
| 8 | input_bar | 底部输入区（含表情/附件等按钮） |
| 9 | single_chat | 分组区「单聊」 |
| 10 | group_chat | 分组区「群聊」 |
| 11 | contact_send_message | 联系人详情「发消息」 |
| 12 | nav_groups_icon | 导航「分组」图标 |

> **顺序不可调整** —— id 就是写进标签文件的类别号。旧版 `contact_item`(4)、`conversation_item`(7)
> 已合并为 `list_item`(4)，`message_input` 已删除。改动前的旧标注不再兼容。

如果 txt 里出现了超出类别表的 id，下拉框会自动补一个 `class_N` 项，不会丢数据。

## 标注提效

- **类别下拉框**：右侧「标注类别」是下拉选择，显示成 `[4] contact_item`，文件里只写数字 id；选中已有框时下拉框会自动切到它的类别，改下拉框即改该框类别。
- **数字键快速赋类别**：选中框后按 `0`~`9`、`-`(=10)、`=`(=11)、`[`(=12) 直接改类别，不用碰鼠标（按键数量按类别表长度自动截断）。
- **按类别配色**：每个类别有固定颜色（不随主题变化），画布上的框按类别上色，选中时同色加粗高亮；框上方直接画出类名。跨类别混标时一眼就能看出标错没有。
- **类别统计**：右侧「类别统计」列出当前图片各类别数量（色块 + `[4] contact_item ×3`），用来核对是否有漏标 / 多标。
- **盖框模式（同尺寸批量落框）**：`contact_item`、`conversation_item` 这类条目长宽一致，先画好一个 → 选中它 → 按 `Ctrl+D` 进入盖框模式 → 在画布上依次单击即可批量落出同尺寸同类别的框 → `Esc` 或右键退出。
- **复制 / 粘贴**：`Ctrl+C` 复制选中框、`Ctrl+V` 粘贴（带偏移）；`Ctrl+Shift+C` 复制当前图全部框，切到下一张图 `Ctrl+V` 就能继承上一张的布局再微调，适合截图风格统一的批量标注。

以上写操作都支持 `Ctrl+Z` 撤回。

## 窗口截图

左侧图片列表下方的 **窗口截图** 按钮会进入一个类似微信截图的选区模式：

1. 鼠标在屏幕上移动，光标所在的窗口会被实时高亮描边，并显示窗口名与像素尺寸；
2. 双击窗口、按 `Enter`、或点高亮框右下角的对勾完成截图；
3. `Esc` 或右键取消。

截图以 PNG 存进**保存路径**，文件名形如 `shot_20261007_101530.png`，并自动插入图片列表、切换过去，可以马上标注。

- 只截目标窗口本身，不会把屏幕上的其他内容或遮罩层拍进去。
- **macOS** 需要 `pyobjc-framework-Quartz` 和「屏幕录制」权限。缺权限时会弹提示，按提示到
  系统设置 → 隐私与安全性 → 屏幕录制 里勾选本程序（从终端启动就勾「终端」），然后重启本程序。
- **Windows** 走 user32/gdi32，无需额外依赖。

## 模型预标注

左侧的 **模型预标注** 按钮会对当前文件夹调用 YOLO 推理服务，为每张图生成**模型预测的框**，
你再人工校正 —— 不用从零开始画。

- 服务地址与推理参数在 设置 → 模型预标注 里配置（默认 `http://192.168.1.13:8080`）。
- 预测结果写成 `<图片名>_model.txt`，**不会碰**你人工保存的 `<图片名>.txt`。
- 打开图片时优先读 `.txt`，没有才回退读 `_model.txt` —— 所以你看到的就是模型的框。
- **人工保存 `<图片名>.txt` 时，同名的 `_model.txt` 会被删掉。** 它的存在与否就是
  「这张图校正过没有」的标记，图片列表据此显示四态：

| 前缀 | 含义 |
|------|------|
| `○` | 未标注（既无人工标注也无预标注） |
| `◐` | 有模型预标注，**等待人工校正** |
| `✓` | 已有人工标注 |
| `●` | 当前图有未保存的修改 |

- 已有人工标注的图片会**自动跳过**，重跑预标注不会把已完成的图打回「待校正」。
- 推理尺寸必须与服务端训练分辨率一致（该权重为 `1280`），调低会大面积漏检。

## 设置

点击菜单栏 **设置** 直接打开偏好面板，可配置：

| 选项 | 说明 | 默认值 |
|------|------|--------|
| 切换图片时自动保存 | 上一张/下一张/列表切换前保存当前图 txt | 开启 |
| 启用定时自动保存 | 按间隔遍历当前文件夹内所有图片并写回 txt | 关闭 |
| 定时间隔 | 定时保存间隔（分钟） | 5 |
| 语言 | 中文 / English / 日本語 | 中文 |
| 快捷键 | Ctrl+S、Ctrl+Z、A、Delete、R、O、P、Enter、Esc 等，可点击输入框后按键修改 | 见上表 |
| 模型预标注 · 服务地址 | YOLO 推理服务地址，任何形态都行（会自动补 `http://`、去掉多余的 `/`） | `http://192.168.1.13:8080` |
| 模型预标注 · 置信度 | 传给 `/predict` 的 `conf` | 0.25 |
| 模型预标注 · IoU | 传给 `/predict` 的 `iou` | 0.7 |
| 模型预标注 · 推理尺寸 | 传给 `/predict` 的 `imgsz`，须与训练分辨率一致 | 1280 |

说明：关闭「切换图片时自动保存」后，未手动保存的编辑在切图时会丢失；定时保存会对文件夹内每张图写盘（当前图用内存数据，其余图用已有 txt）。

## 注意：
代码用的是with open 和写入模式，是覆盖式的，所以如果之前有同名文件，会被覆盖。但这也有好处，因为软件会加载保存路径里现有的标注



## 功能特性

###  图片管理
-  支持打开单张图片
-  支持打开整个文件夹进行批量标注
-  "上一张"和"下一张"按钮快速浏览图片,也可以在文件列表里选择图片
-  图片计数器显示当前进度（如 `3/10`）
-  切换图片时自动保存前一张的标注
-  图片列表
-  列表前缀：`○` 未标注、`✓` 已有 txt、`●` 当前图有未保存修改
### BBox标注
-  新增BBox（自动居中于图像）
-  删除选中的BBox
-  8个拉伸控制点（4个角 + 4条边）
-  鼠标悬停时控制点高亮显示
-  拖拽移动BBox
-  **严格边界检查** - BBox永远不会超出图像范围

### OBB标注

- 可能会超出边界
- 四个角控制点，一个旋转控制点

### Seg 多边形标注

- 与 Rect / OBB **共用同一 `.txt` 文件**，按行混存
- 选择「多边形(Seg)」后点击「新添」，在画布上**左键逐点**添加顶点
- **Enter** 或 **双击首点附近**闭合多边形（至少 3 点）；**Esc** 取消绘制
- **Backspace** 撤销上一个顶点
- 编辑：拖拽顶点；拖拽多边形内部整体平移
- 顶点严格限制在图像范围内

#### YOLO Seg 格式

每行一个实例，归一化顶点坐标（相对图像宽高）：

```
class_id  x1 y1  x2 y2  x3 y3  ...  xn yn
```

示例：

```
0  0.681 0.485  0.670 0.487  0.676 0.487  0.688 0.515
1  0.422 0.315  0.438 0.330  0.445 0.328  0.450 0.320  0.435 0.310
```

**字段数识别规则**（加载时）：

| 字段数 | 类型 |
|--------|------|
| 5 | 标准矩形 (Rect) |
| 9 | OBB 旋转框（4 顶点） |
| 7, 11, 13…（奇数且 ≥7，且 ≠9） | Seg 多边形 |

> **注意**：恰好 9 个字段的行会被解析为 **OBB**，而非 4 顶点的 Seg 多边形。若需要 4 顶点矩形 mask，请使用 OBB 模式，或标注时使用 **≥5 个顶点**。

### 标签管理
-  修改类别（右侧下拉框选择，或选中框后按数字键）
-  列表显示：`[Rect]` / `[OBB]` / `[Poly] IDx | [4] contact_item`（多边形另显示顶点数）
-  点击列表项选中对应BBox
-  点击图像中的BBox自动同步到列表
-  单选模式：同时只有一个BBox为高亮加粗

### 保存和加载
-  打开图片 / 文件夹前必须已有有效的保存路径
-  第一次手动选择；之后启动会自动恢复上次的目录。若目录被删或失效，需要再选一次
-  对应的 `.txt` 从该保存路径加载，保存时也写回这里（同名文件会覆盖）
-  可手动保存，或在切换图片时自动保存
